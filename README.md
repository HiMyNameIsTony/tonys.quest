# heymynameistony.com

The landing page for [heymynameistony.com](https://heymynameistony.com): a small pixel-art pirate tavern in the style of a retro point-and-click adventure game. You walk up to the bar, the barkeep greets you, and you pick what to say from a list of dialogue choices. The first choice takes you to the [Twitch stream](https://www.twitch.tv/heymynameistony); the rest are just banter, with a few easter eggs for anyone who pokes around.

The whole site is a single `index.html` with no build step, frameworks or image files. The scene is drawn in code on a 320×180 canvas and scaled up, and the page makes no third-party requests. It is hosted on GitHub Pages straight from the `main` branch.

The two pixel fonts in `fonts/`, Press Start 2P and VT323, are bundled under the SIL Open Font License; their licence texts sit alongside them.
